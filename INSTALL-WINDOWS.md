# Установка RTSP Atom на Windows 11 (без интернета)

Пакет `rtspatom-<версия>-windows-x64.zip` содержит всё необходимое: Node.js, MediaMTX,
серверную часть, собранный веб-интерфейс и WinSW (обёртка для регистрации служб Windows).
На целевом компьютере ничего скачивать не нужно.

## Требования

- Windows 11 x64. Подойдут и Windows 10 версии 1809 и новее, Windows Server 2019 и новее.
- Права администратора.
- Камеры доступны с этого компьютера по сети (RTSP, обычно порт 554).

## Установка

1. Перенесите на компьютер `rtspatom-…-windows-x64.zip`, например на флешке.
2. **Перед распаковкой** щёлкните архив правой кнопкой → **Свойства** → поставьте галочку
   **«Разблокировать»** → **ОК**. Иначе Windows будет предупреждать о «файлах из интернета».
3. Распакуйте архив: правой кнопкой → «Извлечь все…».
4. Откройте распакованную папку и дважды щёлкните **`install.cmd`**.
   Windows спросит разрешение на изменения — ответьте «Да».
   Если появится синее окно SmartScreen, нажмите «Подробнее» → «Выполнить в любом случае».
5. Придумайте пароль администратора (логин `admin`, не короче 8 символов).

Установщик:

- скопирует программу в `C:\Program Files\RTSPAtom`;
- создаст каталог данных `C:\ProgramData\RTSPAtom` (настройки, база, журналы);
- зарегистрирует две службы — **RTSP Atom** и **RTSP Atom MediaMTX**. Они запускаются вместе с Windows
  от ограниченной учётной записи `LocalService`;
- откроет в брандмауэре Windows порт панели 8080 и порт видео WebRTC 8189 (UDP и TCP);
- положит на рабочий стол ярлык **RTSP Atom**;
- если порт 8080 занят другой программой — сам возьмёт свободный (см. «Порты»).

После установки откройте ярлык **RTSP Atom** или в браузере `http://localhost:8080`.
С других компьютеров используйте адрес `http://<IP этого компьютера>:8080`.

### Порты

По умолчанию панель работает на порту **8080**, видео с минимальной задержкой (WebRTC) идёт по порту
**8189 UDP/TCP** — он должен быть доступен с компьютеров операторов. MediaMTX внутри использует порты
**8888**, **8890** и **9997** (они доступны только с этого компьютера). Установщик сам проверяет порты: если какой-то занят другой
программой, он берёт следующий свободный (8081, 8082 …), пишет об этом и открывает в брандмауэре
именно выбранный порт. Ярлык на рабочем столе ведёт на правильный адрес. При обновлении порты
сохраняются, если они по-прежнему свободны.

> Установщик видит только программы, которые **работают в момент установки**. Если на этом компьютере
> есть другой сервер на порту 8080 (например, ваш второй проект), запустите его перед установкой
> или сразу укажите другой порт: `install.cmd -Port 8090`.

### Параметры установки

Их можно указать в командной строке:

```bat
install.cmd -Port 8090 -Tls
```

| Параметр | Назначение |
|---|---|
| `-Port 8080` | желаемый порт веб-интерфейса (если занят — возьмётся следующий свободный) |
| `-Tls` | включить HTTPS с самоподписанным сертификатом (браузер попросит подтвердить исключение) |
| `-AdminLogin admin` | логин первого администратора |
| `-NoStart` | не запускать службы после установки |
| `-NoFirewall` | не создавать правило брандмауэра |

## Первые шаги

1. **Потоки → Добавить поток.** Укажите название, RTSP-адрес камеры (например
   `rtsp://192.168.1.64:554/Streaming/Channels/101`), логин и пароль камеры. Нажмите **Проверить подключение**.
2. **Видеостена** откроется с камерами сама. Раскладка 1, 4, 9 или 16 камер переключается кнопками или клавишами 1–4,
   камеры переставляются перетаскиванием. **На весь экран** (клавиша F) — полноэкранный режим,
   двойной щелчок по камере разворачивает её одну.
3. **Пользователи:** заведите операторов и наблюдателей и при необходимости ограничьте, какие камеры им видны.

> Браузеры надёжно показывают видео **H.264**. Если камера отдаёт H.265, переключите её на H.264.

## Пост охраны: видеостена сразу во весь экран

Браузер не разрешает сайту самому включать полноэкранный режим без действия человека. Есть два способа:

- на видеостене включите кнопку **«Разворачивать на весь экран»** (значок монитора рядом с «На весь экран»):
  стена развернётся при первом щелчке или нажатии любой клавиши;
- или запускайте браузер в режиме киоска — панель откроется во весь экран сразу. Ярлык для Microsoft Edge:
  ```
  "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --kiosk http://localhost:8080 --edge-kiosk-type=fullscreen
  ```
  Чтобы это происходило при входе в Windows, положите ярлык в папку автозагрузки (`Win+R` → `shell:startup`).
  Выход из режима киоска — `Alt+F4`.

## Обслуживание

Службы видны в «Службы» (`services.msc`) под именами **RTSP Atom** и **RTSP Atom MediaMTX**.
Управлять ими можно также из PowerShell, запущенного от имени администратора:

```powershell
Get-Service rtspatom, rtspatom-mediamtx      # состояние
Restart-Service rtspatom                     # перезапуск панели
```

Журналы лежат в `C:\ProgramData\RTSPAtom\logs`.

Утилита администрирования. Запускайте её в командной строке **от имени администратора**:

```bat
rtspatom-admin list-users
rtspatom-admin reset-password admin
rtspatom-admin create-admin ivanov
rtspatom-admin unblock-ip
rtspatom-admin clear-ip-rules
```

С самого компьютера (`localhost`) IP-фильтр не действует, поэтому доступ к панели здесь есть всегда.

**Настройки** хранятся в `C:\ProgramData\RTSPAtom\config.json` (порт, HTTPS) и `mediamtx.yml`.
После правки перезапустите службы.

**Резервная копия:** остановите службу `rtspatom` и скопируйте каталог `C:\ProgramData\RTSPAtom`.

## Обновление

Распакуйте новый пакет и снова запустите `install.cmd`. База, пользователи и настройки сохранятся.

## Удаление

Запустите `C:\Program Files\RTSPAtom\uninstall.cmd`. Данные в `C:\ProgramData\RTSPAtom` сохранятся.
Чтобы удалить и их, выполните в командной строке:

```bat
"C:\Program Files\RTSPAtom\uninstall.cmd" -Purge
```

## Если что-то не работает

| Признак | Что проверить |
|---|---|
| С других компьютеров страница не открывается | правило брандмауэра «RTSP Atom»; сторонний антивирус или брандмауэр; правила IP-фильтра |
| «Служба MediaMTX недоступна» | службу «RTSP Atom MediaMTX» в `services.msc` и журнал `logs\rtspatom-mediamtx.out.log` |
| Камера «нет сигнала» | адрес и пароль (кнопка «Проверить»); `ping` до камеры; попробуйте транспорт TCP |
| При наведении на камеру написано «HLS», задержка 1–3 с | порт 8189 UDP/TCP закрыт на межсетевом экране между компьютерами (правила `RTSPAtom-ICE-*` в брандмауэре Windows ставит установщик); кодек камеры должен быть H.264 |
| Видео есть в проверке, но не в браузере | кодек H.265 — переключите камеру на H.264 |
| Забыт пароль администратора | `rtspatom-admin reset-password admin` |
| Панель перестала открываться после запуска другой программы на том же порту | запустите `install.cmd` ещё раз — он подберёт свободный порт; или `install.cmd -Port 8090` |
| Антивирус удалил `mediamtx.exe` или `node.exe` | добавьте `C:\Program Files\RTSPAtom` в исключения и запустите установку ещё раз |
