# 🎥 RTSP Сервер "115 обрОсН"

## Полнофункциональная панель управления системами видеонаблюдения

---

## 📋 О системе

**RTSP Сервер "115 обрОсН"** — это современная веб-панель управления системами видеонаблюдения, разработанная для развёртывания в изолированных локальных сетях (Astra Linux, без доступа в Интернет).

Система позволяет управлять множеством компьютеров с IP-камерами, настраивать видеостены, контролировать доступ пользователей и вести журналы событий.

---

## ✨ Основные возможности

### 🖥️ Управление компьютерами и потоками

- **Добавление компьютеров** с указанием hostname, IP, описания
- **Управление потоками** (RTSP, HLS, HTTP-FLV, MPEG-TS)
- **Автоопределение протокола** по URL
- **Проверка доступности** потока перед добавлением
- **Включение/отключение** компьютеров и потоков
- **Иерархическая структура**: компьютер → потоки

### 📺 Видеостена

- **Сетка экранов**: 1×1, 2×2, 3×3, 4×4
- **Полноэкранный режим** без перезагрузки страницы
- **Сохранение конфигураций** в localStorage
- **Автоперезагрузка потоков** (15 сек — 5 часов)
- **Реальное воспроизведение** видео
- **Fallback видео** при ошибках (Big Buck Bunny)
- **Индикаторы статуса** (LIVE/ДЕМО)

### 👥 Пользователи и роли

- **Роли**: администратор, оператор, наблюдатель
- **Назначение прав** администратора (переопределяет роль)
- **Доступ к компьютерам** (выбор конкретных компьютеров)
- **IP-фильтрация** (белый/чёрный списки CIDR)
- **Активация/деактивация** пользователей
- **Смена паролей**

### 📊 Панель управления

- **Метрики в реальном времени**: CPU, RAM, сеть
- **Графики загрузки** системы
- **Статусы компьютеров** и потоков
- **Время работы** системы

### 📝 Журналы событий

- **Категории**: auth, access, stream, error
- **Фильтрация** по дате, пользователю, IP, категории
- **Экспорт в CSV**
- **Поиск** по сообщениям

### 🔒 Безопасность

- **Аутентификация**: bcrypt + JWT
- **Rate limiting**: 5 попыток → блок на 15 мин
- **IP-фильтрация**: белый/чёрный списки
- **Аудит**: все действия логируются
- **Защита роутинга** по ролям

## 📦 Поддерживаемые протоколы

### ✅ Работают напрямую в браузере

|----------|----------|------------|

## 🔧 Настройка RTSP камер

Для работы с RTSP камерами используйте **MediaMTX**:

### Установка

```bash
# Скачайте
wget https://github.com/bluenviron/mediamtx/releases/latest/download/mediamtx_linux_amd64.tar.gz

# Распакуйте
tar -xzf mediamtx_linux_amd64.tar.gz

# Запустите
./mediamtx
```

### Конфигурация

Откройте `mediamtx.yml`:

```yaml
paths:
  camera1:
    source: rtsp://192.168.1.100:554/stream1
    sourceProtocol: tcp
  
  camera2:
    source: rtsp://192.168.1.101:554/stream1
    sourceProtocol: tcp
```

### Использование

В системе добавьте поток:
- URL: `http://localhost:8888/camera1/hls`
- Протокол: HLS (определяется автоматически)

## 🎯 Сценарии использования

### Сценарий 1: Малый офис

**Задача:** Мониторинг 5 камер в офисе

**Решение:**
1. Установите MediaMTX на локальный сервер
2. Добавьте 5 RTSP камер
3. В системе создайте 1 компьютер "Офис"
4. Добавьте 5 потоков (HTTP-FLV или HLS)
5. Настройте видеостену 3×2

### Сценарий 2: Предприятие

**Задача:** Мониторинг 50 камер на территории

**Решение:**
1. Установите MediaMTX на выделенный сервер
2. Создайте несколько компьютеров по зонам
3. Настройте пользователей с разными ролями
4. Создайте конфигурации видеостены для разных задач

### Сценарий 3: Изолированная сеть

**Задача:** Развёртывание в сети без доступа в Интернет

**Решение:**
1. Соберите проект: `npm run build`
2. Скопируйте папку `dist/` на локальный сервер
3. Разверните на веб-сервере (nginx, Apache)
4. Настройте MediaMTX локально

## 🆘 Поддержка

### Проблемы и решения

**Видео не воспроизводится:**
- Проверьте URL потока
- Убедитесь что сервер отдаёт CORS заголовки
- Используйте MediaMTX для RTSP камер

**Не могу войти:**
- Логин: `admin`
- Пароль: `admin`
- Очистите localStorage: `localStorage.clear()` в консоли (F12)

**MediaMTX не запускается:**
- Проверьте что порты 8554, 8888, 1935 свободны
- Запустите от имени администратора
