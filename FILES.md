## ✅ Контрольная сумма

Для проверки целостности файлов используйте:

```bash
# Linux/Mac
find . -type f -not -path "./node_modules/*" -not -path "./dist/*" -exec md5sum {} \; > checksums.md5

# Windows (PowerShell)
Get-ChildItem -Recurse -File -Exclude node_modules,dist | ForEach-Object { 
    (Get-FileHash $_.FullName -Algorithm MD5).Hash + "  " + $_.FullName 
} | Out-File checksums.md5
```
