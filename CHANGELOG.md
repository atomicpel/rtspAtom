# Changelog

## [1.0.0] - 2024 - Релиз

### ✨ Добавлено

#### Архитектура
- **Концепция «Систем»**: удалённые рабочие столы с набором камер
- **Гибкая система ролей**: администратор, оператор, наблюдатель
- **Назначение прав админа**: любой пользователь может получить полные права
- **Доступ к системам**: админ определяет, какие системы доступны каждому пользователю

#### Страницы
- **Панель управления**: метрики CPU/RAM, графики в реальном времени, статусы систем
- **Видеостена**: сетка 1×1 / 2×2 / 3×3 / 4×4, выбор камер, сохранение конфигураций
- **Системы**: управление системами и камерами (только для админа)
- **Пользователи**: создание, роли, права, доступ к системам
- **IP-фильтр**: белый/чёрный списки CIDR
- **Журналы**: auth.log, access.log, stream.log, error.log + экспорт CSV
- **Настройки**: TLS, TTL сессий, лимиты, формат логов
- **О системе**: информация + надпись «115 обрОсН»

#### Видеостена
- Layout'ы: 1×1, 2×2, 3×3, 4×4
- Иерархический выбор камер (система → камера)
- Автозаполнение активными камерами
- Сохранение и загрузка конфигураций
- **Полноэкранный режим видеостены** — на весь экран без меню и хедера
- **Автоперезагрузка потоков** — настраиваемый интервал: 15 сек, 30 сек, 1 мин, 3 мин, 5 мин, 10 мин, 15 мин, 30 мин, 1 час, 2 часа, 3 часа, 5 часов
- Полноэкранный просмотр отдельной камеры
- Визуальная обратная связь при автоперезагрузке
- Фильтрация по доступным системам

#### Безопасность
- Хеширование паролей (mock bcrypt)
- JWT-сессии
- Rate limiting: 5 неудачных попыток → блок на 15 минут
- IP-фильтрация (белый/чёрный списки CIDR)
- Аудит всех действий в журналы
- Защита роутинга по ролям

#### Интерфейс
- Тёмная тема по умолчанию + переключатель
- Анимированный фон с частицами
- Glassmorphism эффекты
- Плавные переходы между страницами
- Stagger-анимации для списков
- Toast-уведомления
- Адаптивный дизайн (десктоп + планшет)

#### Данные
- Seed-данные: 3 тестовые системы (КПП-1, Периметр, Склад) с камерами
- Первый вход: создание администратора
- Демо-вход: admin/admin

### 🛠️ Технологии
- React 18 + TypeScript + Vite
- Tailwind CSS + Framer Motion
- Recharts (графики)
- Lucide React (иконки)
- localStorage (имитация SQLite)
