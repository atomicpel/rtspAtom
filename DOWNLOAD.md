## 🚀 Быстрый старт (5 минут)

### Шаг 1: Установите Node.js

**Windows:**
1. Скачайте: https://nodejs.org/
2. Установите (Next → Next → Finish)
3. Проверьте: `node --version`

**Linux:**
```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs
```

**macOS:**
```bash
brew install node
```

### Шаг 2: Распакуйте архив

```bash
unzip rtsp-server-115-obroshn.zip
cd rtsp-server-115-obroshn
```

### Шаг 3: Установите зависимости

```bash
npm install
```

### Шаг 4: Запустите

```bash
npm run dev
```

### Шаг 5: Откройте браузер

```
http://localhost:5173
```

**Вход:**
- Логин: `admin`
- Пароль: `admin`

**Готово!** 🎉

## 🎬 Как использовать

### 1. Добавление компьютера

1. Откройте **"Компьютеры"**
2. Нажмите **"Добавить компьютер"**
3. Заполните:
   - Название: "КПП-1"
   - Hostname: "kpp1-server"
   - IP: "192.168.1.10"
   - Описание: "Центральный пост"
4. Нажмите **"Добавить"**

### 2. Добавление потока

1. Раскройте компьютер
2. Нажмите **"Добавить поток"**
3. Введите URL:
   ```
   https://test-streams.mux.dev/x36xhzz/x36xhzz.m3u8
   ```
4. Система автоматически определит протокол (HLS)
5. Нажмите **"Проверить"**
6. Нажмите **"Добавить"**

### 3. Настройка видеостены

1. Откройте **"Видеостена"**
2. Выберите сетку (2×2)
3. Нажмите на ячейку
4. Выберите компьютер и поток
5. Видео начнёт воспроизводиться
6. Нажмите **"Сохранить"**

## 🔧 Настройка RTSP камер

Для работы с RTSP камерами используйте **MediaMTX**:

### Установка MediaMTX

1. Скачайте: https://github.com/bluenviron/mediamtx/releases
2. Распакуйте
3. Запустите: `./mediamtx`

### Конфигурация

Откройте `mediamtx.yml`:

```yaml
paths:
  camera1:
    source: rtsp://192.168.1.100:554/stream1
    sourceProtocol: tcp
```

### Использование

В системе добавьте поток:
- URL: `http://localhost:8888/camera1/hls`
- Протокол: HLS (определяется автоматически)

## 🆘 Поддержка

### Проблемы и решения

**Видео не воспроизводится:**
- Проверьте URL потока
- Убедитесь что сервер отдаёт CORS заголовки
- Используйте MediaMTX для RTSP камер

**Не могу войти:**
- Логин: `admin`
- Пароль: `admin`
- Очистите localStorage: `localStorage.clear()` в консоли браузера (F12)

**MediaMTX не запускается:**
- Проверьте что порты 8554, 8888, 1935 свободны
- Запустите от имени администратора
