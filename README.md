## ⚠️ Почему ваш поток может не работать

### Проблема CORS
Браузеры блокируют загрузку видео с других доменов если сервер не отдаёт CORS заголовки.

**Пример:** `https://cdn.ntv.ru/...` — не работает из-за CORS.

### Решение: MediaMTX

MediaMTX — простой сервер который:
- Конвертирует RTSP → HLS/HTTP-FLV
- Обходит CORS
- Работает с любыми потоками

**Установка:**
1. Скачайте: https://github.com/bluenviron/mediamtx/releases
2. Запустите: `./mediamtx`
3. Добавьте в конфиг `mediamtx.yml`:

```yaml
paths:
  camera1:
    source: rtsp://192.168.1.100:554/stream1
    sourceProtocol: tcp
  
  ntv:
    source: https://cdn.ntv.ru/unknown_russia/tracks-v1a1/playlist.m3u8
```

4. Используйте URL в системе:
   - `http://localhost:8888/camera1` (HTTP-FLV)
   - `http://localhost:8888/camera1/hls` (HLS)
   - `http://localhost:8888/ntv/hls` (HLS для ntv)

## 📝 Важные замечания

### Ограничения браузеров
Браузеры НЕ могут напрямую воспроизводить RTSP/RTMP. Нужен сервер-конвертер (MediaMTX).

### CORS
Многие серверы блокируют загрузку из браузера. Решение: использовать MediaMTX как прокси.

### Fallback видео
Если поток не загружается, система показывает демо видео. Это нормально! Используйте локальный HLS сервер для реальных потоков.
