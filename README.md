# 🎥 RTSP Сервер — 115 обрОсН

Панель управления системами видеонаблюдения с поддержкой множественных протоколов потокового видео.

## ✨ Что нового

### 🎬 Реальное воспроизведение видео
- **HLS/m3u8 потоки** — воспроизводятся напрямую в браузере через hls.js
- **HTTP/HTTPS видео** — MP4, WebM и другие форматы
- **Автоопределение протокола** — система сама определяет тип потока по URL
- **Проверка потока** — кнопка проверки доступности потока перед добавлением

### 🖥️ Видеостена
- Сетка 1×1, 2×2, 3×3, 4×4
- Полноэкранный режим (CSS-based, без перезагрузки страницы)
- Сохранение конфигураций в localStorage
- Автоперезагрузка потоков (15 сек — 5 часов)
- Реальное воспроизведение видео в каждой ячейке

### 🖥️ Компьютеры и потоки
- Управление компьютерами с множеством потоков
- Поддержка протоколов: RTSP, RTMP, HLS, HTTP, HTTPS, FLV, MPEG-TS, WebRTC
- Автоматическое определение типа протокола при вводе URL
- Проверка доступности потока

## 📺 Поддерживаемые протоколы

### ✅ Работают напрямую в браузере

**HLS (m3u8)**
- URL формат: `https://server/stream.m3u8`
- Воспроизводится через hls.js
- Рекомендуется для IP-камер

**HTTP/HTTPS (MP4, WebM)**
- URL формат: `https://server/video.mp4`
- Воспроизводится через video тег

### ⚠️ Требуют сервер-конвертер

**RTSP**
- URL формат: `rtsp://camera-ip:554/stream`
- Требуется конвертер: MediaMTX, SRS или FFmpeg
- Конвертация: RTSP → HLS

**RTMP**
- URL формат: `rtmp://server/live/stream`
- Требуется конвертер в HLS/WebRTC

**FLV**
- URL формат: `http://server/stream.flv`
- Требуется конвертер в HLS

## 🔧 Настройка RTSP камер

Если у вас RTSP камеры, используйте один из вариантов:

### Вариант 1: MediaMTX (рекомендуется)

1. Скачайте MediaMTX: https://github.com/bluenviron/mediamtx/releases
2. Запустите: `./mediamtx`
3. Добавьте RTSP камеру в конфиг:
```yaml
paths:
  camera1:
    source: rtsp://192.168.1.100:554/stream1
    sourceProtocol: tcp
```
4. Используйте HLS URL в системе: `http://localhost:8888/camera1/hls`

### Вариант 2: FFmpeg

```bash
ffmpeg -i rtsp://camera-url -c copy -f hls \
  -hls_time 2 -hls_list_size 5 \
  -hls_flags delete_segments \
  output.m3u8
```

Затем используйте URL файла output.m3u8 в системе.

### Вариант 3: SRS (Simple Realtime Server)

Профессиональное решение для видеостриминга.
Документация: https://github.com/ossrs/srs

## 🎯 Тестовые данные

Система поставляется с тестовыми HLS потоками которые работают из коробки:

- **КПП-1** — 3 HLS потока (публичные тестовые потоки)
- **Периметр** — 2 HLS потока
- **Склад** — 1 HLS поток

Все тестовые потоки воспроизводятся сразу после входа.

## 📝 Примечания

### Ограничения браузеров

Браузеры **не могут** напрямую воспроизводить:
- RTSP потоки
- RTMP потоки
- FLV потоки

Это физическое ограничение браузеров, не нашей системы.

### Решение для RTSP камер

Для работы с RTSP камерами нужен сервер-конвертер который преобразует RTSP в HLS:

1. **MediaMTX** — простой в настройке, бесплатный
2. **FFmpeg** — универсальный инструмент
3. **SRS** — профессиональное решение

После конвертации используйте HLS URL (заканчивается на .m3u8) в системе.
