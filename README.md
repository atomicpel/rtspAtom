# 🎥 RTSP Сервер — 115 обрОсН

Панель управления системами видеонаблюдения с множеством камер.  
Развёртывание в изолированной локальной сети (Astra Linux, без доступа в Интернет).

---

## 🚀 Быстрый старт

```bash
npm install
npm run dev
```

Откройте http://localhost:5173

**Первый вход:** создайте администратора (любые логин/пароль).  
**Демо-вход:** `admin` / `admin` (если база уже инициализирована).

---

## 📦 Сборка для продакшена

```bash
npm run build
```

Результат в папке `dist/` — можно развернуть на любом статическом хостинге или файловом сервере.

## 🏗️ Архитектура

### Концепция «Систем»

Каждая **система** — это удалённый рабочий стол компьютера с набором камер:
- **hostname** + **IP-адрес** — адрес удалённого компьютера
- **Камеры** — RTSP-потоки, подключённые к этому компьютеру

Пример: система «КПП-1» может содержать 3 камеры (въезд, выезд, внутренний пост).

### Роли и права

| Роль | Доступ |
|------|--------|
| **Администратор** (`isAdmin=true`) | Полный доступ: системы, пользователи, настройки, IP-фильтр, журналы |
| **Оператор** | Видеостена + журналы (только разрешённые системы) |
| **Наблюдатель** | Только видеостена (только разрешённые системы) |

- Администратор может назначить **права админа** любому пользователю (галочка «Права админа»)
- Админ определяет, **какие системы** доступны каждому пользователю
- Если список систем пуст — пользователю доступны все системы

### Безопасность

- Хеширование паролей (mock bcrypt)
- JWT-сессии (HttpOnly cookie в продакшене)
- Rate limiting: 5 неудачных попыток → блок на 15 минут
- IP-фильтрация (белый/чёрный списки CIDR)
- Аудит всех действий в журналы

## 🎬 Видеостена

- **Layout'ы:** 1×1, 2×2, 3×3, 4×4
- **Выбор камер:** иерархический пикер (система → камера)
- **Автозаполнение:** автоматическая расстановка активных камер
- **Сохранение конфигураций:** именованные раскладки в localStorage
- **Полноэкранный режим:** просмотр видеостены на весь экран (без меню и хедера)
- **Автоперезагрузка потоков:** настраиваемый интервал (15 сек — 5 часов)
- **Полноэкранный просмотр:** отдельная камера на весь экран
- **Фильтрация:** показываются только разрешённые пользователю системы
