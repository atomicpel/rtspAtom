# 📦 RTSP Сервер "115 обрОсН" — Полный пакет

## 🎯 Что это?

Полнофункциональная панель управления системами видеонаблюдения для изолированных локальных сетей.

**Возможности:**
- ✅ Управление компьютерами и RTSP/HLS/HTTP-FLV/MPEG-TS потоками
- ✅ Видеостена с сеткой 1×1, 2×2, 3×3, 4×4
- ✅ Полноэкранный режим
- ✅ Сохранение конфигураций
- ✅ Автоперезагрузка потоков
- ✅ Пользователи и роли (admin/operator/viewer)
- ✅ IP-фильтрация
- ✅ Журналы событий
- ✅ Панель управления с графиками
- ✅ Безопасность (JWT, rate limiting, аудит)

**Технологии:**
- React 18 + TypeScript + Vite
- Tailwind CSS + Framer Motion
- hls.js + mpegts.js для видео
- localStorage для данных

## 🎬 Как использовать

### Добавление компьютера

1. Откройте **"Компьютеры"**
2. Нажмите **"Добавить компьютер"**
3. Заполните: Название, Hostname, IP, Описание
4. Нажмите **"Добавить"**

### Добавление потока

1. Раскройте компьютер
2. Нажмите **"Добавить поток"**
3. Введите URL (например: `https://test-streams.mux.dev/x36xhzz/x36xhzz.m3u8`)
4. Система автоматически определит протокол
5. Нажмите **"Проверить"**
6. Нажмите **"Добавить"**

### Настройка видеостены

1. Откройте **"Видеостена"**
2. Выберите сетку (1×1, 2×2, 3×3, 4×4)
3. Нажмите на ячейку
4. Выберите компьютер и поток
5. Видео начнёт воспроизводиться
6. Нажмите **"Сохранить"**

## 🔧 Настройка RTSP камер

Для работы с RTSP камерами используйте **MediaMTX**:

### 1. Установка MediaMTX

```bash
# Скачайте с https://github.com/bluenviron/mediamtx/releases
# Распакуйте и запустите
./mediamtx
```

### 2. Конфигурация

Откройте `mediamtx.yml`:

```yaml
paths:
  camera1:
    source: rtsp://192.168.1.100:554/stream1
    sourceProtocol: tcp
```

### 3. Использование

В системе добавьте поток:
- URL: `http://localhost:8888/camera1/hls`
- Протокол: HLS (определяется автоматически)

## 🆘 Поддержка

### Проблемы и решения

**Видео не воспроизводится:**
- Проверьте URL потока
- Убедитесь что сервер отдаёт CORS заголовки
- Используйте MediaMTX для RTSP камер

**Не могу войти:**
- Логин: `admin`
- Пароль: `admin`
- Очистите localStorage: `localStorage.clear()` в консоли браузера

**MediaMTX не запускается:**
- Проверьте что порты 8554, 8888, 1935 свободны
- Запустите от имени администратора
